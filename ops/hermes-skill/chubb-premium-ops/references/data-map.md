# Chubb Premium Data Map

| Area | Canonical files | Notes |
| --- | --- | --- |
| Product rules | `data/product/*.json` | Benefits, labels, schedules, plan rules |
| Premium and rider rates | `data/rates/*.json` | Preserve exact age/gender/product schema |
| Cash value | `data/cv/*.json` | Policy-year cash values and related tables |
| Commission | `data/com/*.json` | Commission-rate data |
| Medical/facility data | `data/MF/*.json` | Company/facility datasets |
| Calculator logic | `js/calculator.js`, `js/ui.js` | Core calculations and single-plan output |
| Comparison logic | `js/compare.js` | Must match the single-plan result |
| UI and content | `index.html`, `css/`, `js/` | Static client experience |
| Access/alerts | `apps-script/Code.gs` | Separate Google Apps Script deployment |
| Hosting identity | `.openai/hosting.json` | Store only the opaque Sites project ID |
| Production build | `dist/client/`, `dist/server/` | Generated by `npm run build` |

## Storage Model

The editable source and static datasets are versioned in GitHub and checked out
on the Codex VPS at `/workspaces/Chubb-Premium`. GPT Sites stores its own source
repository and immutable deployed versions. It does not replace GitHub and it is
not the application's general-purpose database.

Do not add a database or move JSON into an external service unless the user
explicitly requests a persistence redesign.
