# Hermes Telegram Commands

## Add or edit data and publish

```text
Hermes: ใช้สกิล chubb-premium-ops แก้ Chubb Premium
เพิ่ม/แก้ข้อมูล [ระบุสินค้า ตาราง ปี อายุ เพศ และค่าที่ถูกต้อง]
ตรวจ JSON, test 1008/1008 และ build
ถ้าผ่านให้ commit, push GitHub และ deploy ขึ้น
https://chubb-premium.flooksatawat.chatgpt.site ทันที
สรุปเฉพาะสิ่งที่เปลี่ยน ผลทดสอบ commit และ URL ห้ามส่ง token
```

## Edit UI or calculator logic and publish

```text
Hermes: ใช้สกิล chubb-premium-ops แก้ [หน้าจอ/สูตร/พฤติกรรม] ใน Chubb Premium
ตรวจทั้งหน้ารายแบบและหน้าเปรียบเทียบ เพิ่ม regression test ที่จำเป็น
ถ้าทุก test และ build ผ่าน ให้ commit, push และ deploy production ทันที
```

## Prepare without publishing

```text
Hermes: ใช้สกิล chubb-premium-ops เตรียมการแก้ [รายละเอียด]
ตรวจ test และ build แล้วสรุป diff แต่ยังไม่ commit, push หรือ deploy
```

## Status

```text
Hermes: ใช้สกิล chubb-premium-ops ตรวจสถานะ Chubb Premium บน Codex VPS
รายงาน branch, commit, working tree, 1008/1008, build และ production URL
ห้ามแสดง credential หรือ raw connector output
```
